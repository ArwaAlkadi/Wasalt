# 🚆 Wasalt

Wasalt is an iOS application developed as part of Apple Developer Academy to improve public transportation accessibility for people with hearing difficulties.

## Features

- Select a destination metro station
- View the estimated arrival time
- GPS-based station detection using official metro station coordinates
- Vibration alerts before reaching the selected station
- Flashlight alerts for people with hearing difficulties
- Push notifications when approaching the destination
- Accessible and intuitive user interface

## Tech Stack

- Swift
- SwiftUI
- CoreLocation
- UserNotifications
- AVFoundation
- MVVM
- Xcode

## Data Sources

- Official metro station coordinates
- GPS location data
